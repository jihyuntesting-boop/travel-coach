# 서비스 기획서: 연구질문 코치

## 1. 서비스 개요
- **서비스명**: 연구질문 코치
- **목적**: 논문 주제를 정하지 못한 학습자가 전공과 관심 키워드만으로 연구 질문 후보와 문헌 검색 키워드를 빠르게 얻도록 돕는다.
- **타겟 사용자**: 학위논문 주제를 탐색하는 학부 4학년, 석사·박사 과정 대학원생
- **제공 가치**: 빈 화면에서 시작하는 부담을 줄이고, 선행 연구 탐색의 출발점을 제공한다.

## 2. 페이지(섹션) 구성
단일 페이지에서 상단 메뉴(모바일은 햄버거 메뉴)로 섹션 이동한다.

| 섹션 | 내용 |
|---|---|
| 홈 | 서비스 한 줄 소개, AI 코치로 이동하는 버튼 |
| 서비스 소개 | 입력 → 제안 → 탐색 3단계 설명, 주의 문구 |
| AI 코치 | 입력 폼과 결과 영역 |
| FAQ | 저장 여부, 결과 활용, 지연 시 안내 |

## 3. 핵심 기능: AI 연구 질문 제안
- **입력**
  - 전공 분야(필수, 60자 이하)
  - 학위 과정(학부, 석사, 박사 중 선택)
  - 관심 키워드(필수, 200자 이하)
- **출력**
  - 연구 질문 후보 3개와 각 이유
  - 문헌 검색 키워드 5~8개
  - 범위에 대한 주의점 한 문장
- **호출 구조**: 브라우저 `fetch('/api/coach')` → Vercel Serverless Function(Python) → Gemini API

## 4. 실패 처리 기준
| 상황 | 감지 위치 | 사용자 안내 |
|---|---|---|
| 필수값 누락 | 프론트와 서버 모두 | "필수값을 입력하세요." |
| 길이 초과 | 서버(프론트는 maxlength) | 초과 항목과 허용 글자 수 안내 |
| AI API 오류(4xx/5xx) | 서버가 502로 변환 | "AI 서비스 호출에 실패했습니다. 잠시 후 다시 시도하세요." |
| 응답 형식 오류 | 서버 | "AI 응답을 해석하지 못했습니다." |
| 지연 | 프론트 | 8초 후 대기 안내, 25초 후 중단하고 시간 초과 안내 |
| 네트워크 오류 | 프론트 | "네트워크 오류입니다." |
| 서버 키 미설정 | 서버 | 키 이름을 노출하지 않는 일반 안내 |

## 5. 운영·비용 고려
- 출력 토큰을 900으로 제한하고, 입력 길이를 제한한다.
- 요청 본문은 4KB로 제한한다.
- AI 호출 재시도는 1회로 제한한다.
- 입력은 저장하지 않는다.

## 6. 보너스(UX 고도화)
- 다크 모드(시스템 설정 자동 감지와 수동 전환), 카드 호버와 결과 페이드인 같은 마이크로 인터랙션, 현재 섹션 메뉴 강조
